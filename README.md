# עמדת שיעורים — Shiurim Station

![banner](docs/banner.svg)

**גרסה 0.3.0** | Windows 10/11 | Node.js (לפיתוח) — ה-EXE עצמאי לחלוטין

תוכנה אחת, שני שימושים — הכל רץ **מקומית** על המחשב (127.0.0.1 בלבד), בלי התקנה ובלי תלות בשירות חיצוני:

1. **סייר קבצים מסונן** — תחליף לסייר הקבצים של Windows להעברת הקלטות בין מכשירים: רק קובצי אודיו של שיעורים מוצגים וניתנים להעתקה.
2. **עמדת שיעורים** — מחשב עמדה עם ספריית שיעורים מקומית: העתקה מהמכשיר, העלאת הקלטות עם התחברות מקליט, וניהול ע"י אחראי.

---

## 📥 הורדה והתקנה

### חבילה מוכנה (מומלץ — בלי להתקין שום דבר)

| קובץ | קישור |
|---|---|
| `shiurim-station-v0.3.0.zip` (כולל `shiurim-station.exe` + `node.exe` מאורז) | [הורדת ה-zip](https://github.com/chezy734-ship-it/kosher-file-station/raw/main/dist/shiurim-station-v0.3.0.zip) |
| `shiurim-station.exe` (בלבד) | [הורדה ישירה](https://github.com/chezy734-ship-it/kosher-file-station/raw/main/dist/shiurim-station.exe) |
| `KosherShell.exe` (מעטפת חלון) | [הורדה ישירה](https://github.com/chezy734-ship-it/kosher-file-station/raw/main/dist/KosherShell.exe) |

חלצו את ה-zip והריצו:

```
shiurim-station.exe --explorer   ← סייר קבצים מסונן
shiurim-station.exe --station    ← עמדת שיעורים
```

ה-EXE עצמאי לחלוטין — כולל `node.exe` מאורז, **בלי צורך בהתקנת Node.js ובלי דפדפן**. יציאה מהחלון דורשת את סיסמת האחראי.

### מהקוד (למפתחים)

```bash
node server.js        # דורש Node.js LTS
```

ואז בדפדפן: `http://127.0.0.1:8787` (סייר) או `http://127.0.0.1:8787/station` (עמדה).

**מצב קיוסק:** `start-explorer.bat` / `start-station.bat` מריצים את השרת + Chrome ב-`--kiosk`.

**בדיקות:**

```bash
node --test          # בדיקות יחידה של מנוע הסינון
node scripts/e2e.js  # בדיקת קצה-לקצה (דורשת שרת רץ)
```

## 🛡️ סייר קבצים מסונן — יכולות

| יכול | מימוש |
|---|---|
| רק סוגי קבצים מורשים | רשימת סיומות ניתנת להגדרה (ברירת מחדל: mp3, m4a, m4b, wav, flac, ogg, wma, aac). כל קובץ אחר **מוסתר לחלוטין** |
| מגבלת גודל | גודל מקסימלי (MB) בהגדרות |
| מגבלת אורך הקלטה | טווח דקות (ברירת מחדל 20–120), נקרא ישירות מהקבצים / ffprobe |
| מניעת העברה מרובה | מגבלת כמות קבצים בפעולה (ברירת מחדל 6) |
| התגברות על שינוי סיומת | בדיקת **תוכן אמיתי** (magic bytes) — קובץ ששמו `.mp3` אבל תוכנו אחר מסונן החוצה |
| הסתרת כונני מערכת | רק התקנים נשלפים (USB/כרטיס) מוצגים |
| מניעת צפייה בתמונות | רשימה בלבד — אין תצוגת סמלים/תמונות (אלא אם הורשה בהגדרות) |
| המרה ל-MP3 | כפתור "המר ל-MP3" (דורש `ffmpeg.exe` לצד התוכנה או ב-PATH) |
| העברה אמיתית | גזור + הדבק, הוצאה בטוחה, בחירת טווח (Ctrl/Shift) |
| כפילות חכמה | "העתק והחלף / שמור את שניהם / דלג / ביטול" |
| הגנה | הגדרות מוגנות בסיסמה (scrypt hash); בהפעלה ראשונה — מסך הגדרה |
| היסטוריה | כפתור "📜 היסטוריה" — מה הועתק/הועבר/הומר בסשן |

## 🎙️ עמדת השיעורים — יכולות

- **משתמש רגיל** — דפדוף במכשיר (רק אודיו מסונן), חיפוש, העתקה לספריית השיעורים, בדיקת מקום פנוי
- **מקליט** — התחברות בשם משתמש + סיסמה, מוגבל לרבנים שנקבעו לו, תבנית שם קבועה אוטומטית:
  `2026-08-12_הרב כהן_12_גמרא בבא מציעא.mp3` — המקליט ממלא רק מספר שיעור ונושא (תצוגה מקדימה חיה)
- **המרה ל-MP3 בהעלאה** — תיבת סימון (ffmpeg)
- **היסטוריה ואחריות** — כל העלאה נרשמת (מי, מה, למי, מתי); האחראי רואה הכול, המקליט רק את שלו
- **אחראי** — ניהול מקליטים, הרשאות, היסטוריה מלאה, ניהול קבצי הספרייה, יציאה למחשב רגיל

## 📁 קבצים ותיקיות

| קובץ | תפקיד |
|---|---|
| `server.js` | השרת המקומי (API + ממשק) |
| `lib/filter.js` | מנוע הסינון (נבדק ביחידות) |
| `lib/audio.js` | קריאת אורך הקלטות + זיהוי תוכן + המרה |
| `lib/drives.js` | זיהוי כוננים, סוג, שטח פנוי, סריאלי |
| `lib/copy.js` | העתקה עם התקדמות, אשפה, בדיקת מקום |
| `lib/users.js`, `lib/store.js` | מקליטים, היסטוריה, יומן |
| `shell/` | מעטפת חלון .NET (WebView2) — מרכיבה את `shiurim-station.exe` |
| `dist/` | תיקיית הפצה (exe + node.exe מאורז) — נוצרת ע"י `build-dist.bat` |

> `config.json`, `users.json` והיסטוריה **לא** נכללים בגיט — רק `config.example.json` עולה.

## 🔐 אבטחה

- השרת מקשיב **רק** על `127.0.0.1` — אין גישה מהרשת
- סיסמאות כ-scrypt hash, לעולם לא כטקסט
- הפעלות (sessions) בזיכרון בלבד, עם תוקף
- שום נתון לא יוצא מהמחשב

## ⚠️ הערות חשובות

- **זיהוי התקן (סריאלי):** בקוראי כרטיסים זולים המספר הסריאלי הוא של הקורא, לא של הכרטיס — לכן השיטה האמינה היא **שם משתמש + סיסמה + היסטוריית העלאות**; הסריאלי מוצג כמידע עזר בלבד.
- **מנוע AI לזיהוי שיעור-לעומת-שיר** — לא יושם בכוונה; הסינון (אורך + גודל + תוכן + כמות) מכסה את רוב המקרים באמינות.
- **חסימת Ctrl+Alt+Del** — אי אפשר מתוך אפליקציה רגילה; זה תפקיד תוכנת הקיוסק החיצונית, והתוכנה משתלבת איתה.
- **מצב דמו:** ה-`config.json` מגיע עם כונן `C:` מורשה וספריית `library-demo`; משתמש מקליט `בחור-מקליט`/`rec1234` מורשה ל"הרב כהן". להפעלה אמיתית — הגדירו סיסמה, כוננים וספריית שיעורים משלכם.
