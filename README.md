# עמדת שיעורים — עמדת העתקה מקומית 🎙️

תוכנה אחת, שני שימושים:

1. **סייר קבצים מסונן** (`http://127.0.0.1:8787`) — תחליף לסייר הקבצים של ווינדוס להעברת
   הקלטות בין מכשירים: רק קובצי אודיו של שיעורים מוצגים וניתנים להעתקה.
2. **עמדת שיעורים** (`http://127.0.0.1:8787/station`) — מחשב עמדה עם ספריית שיעורים מקומית:
   העתקה מהמכשיר, העלאת הקלטות עם התחברות מקליט, וניהול ע"י אחראי.

הכל רץ מקומית על המחשב (127.0.0.1 בלבד), ללא התקנה וללא תלות בשירות חיצוני —
בדיוק כדי **לא** להיות תלויים בשירותי העברת שיעורים חיצוניים, האיטיים והמסוכנים.

---

## התקנה והרצה

**מעטפת חלון (מומלץ — בלי להתקין שום דבר):** הורידו את ה-zip מהמהדורות, חלצו והריצו
`shiurim-station.exe`. ה-exe עצמאי לחלוטין — כולל `node.exe` מאורז, בלי צורך בהתקנת
Node.js ובלי דפדפן. הרצה: `shiurim-station.exe --explorer` או `--station`.
יציאה מהחלון דורשת את סיסמת האחראי.

**הרצה מהקוד (למפתחים):** דורש [Node.js](https://nodejs.org) (LTS).

```bash
node server.js
```

ואז פתחו בדפדפן:
- סייר מסונן: `http://127.0.0.1:8787`
- עמדת שיעורים: `http://127.0.0.1:8787/station`

**מצב קיוסק עם דפדפן:** `start-explorer.bat` או `start-station.bat` מריצים את השרתחים
Chrome ב-`--kiosk` (דורש Node.js מותקן).

> חסימת `Ctrl+Alt+Del` נעשית ע"י תוכנת הקיוסק הקיימת שלכם — התוכנה הזו משתלבת איתה.
> `build-dist.bat` מרכיב את `dist\` כולל העתקה אוטומטית של `node.exe` מהמערכת — כך
> שההפצה עובדת על כל מחשב בלי שום התקנה.

בדיקות:

```bash
node --test          # בדיקות יחידה של מנוע הסינון
node scripts/e2e.js  # בדיקת קצה-לקצה (דורשת שרת רץ)
```

## סייר קבצים מסונן — התאמה לדרישות בקשה א'

| דרישה | מימוש |
|---|---|
| **א. רק סוגי קבצים מורשים** | רשימת סיומות ניתנת להגדרה (ברירת מחדל: mp3, m4a, m4b, wav, flac, ogg, wma, aac). כל קובץ אחר **מוסתר לחלוטין** — שמו אפילו לא מופיע. |
| **ב. מגבלת גודל** | גודל מקסימלי (MB) בהגדרות; קובץ גדול יותר לא מוצג. |
| **ג. מגבלת אורך הקלטה** | טווח דקות (ברירת מחדל 20–120). אורך נקרא מקבצי MP3 / WAV / M4A / FLAC ישירות, ובפורמטים אחרים ע"י ffprobe אם קיים. |
| **ד. מניעת העברת קבצים מרובה** | מגבלת כמות קבצים בפעולה (ברירת מחדל 6). |
| **התגברות על שינוי סיומת** | בדיקת **תוכן אמיתי** (magic bytes): קובץ ששמו `.mp3` אבל תוכנו טקסט/וידאו מסונן החוצה. בנוסף, קבצים שאי אפשר לקבוע את אורכם מוסתרים כברירת מחדל — כך "השיר" שנשמר כ-`123.mp3` יתגלה. |
| **הסתרת כונני מערכת** | רק התקנים נשלפים (USB/כרטיס) מוצגים. ניתן להוסיף אותיות כונן מורשות (למשל כונן עמדה קבוע). |
| **מניעת צפייה בתמונות/תמונות אלבום** | הממשק מציג רשימה בלבד — אין תצוגת סמלים/תמונות כלל. |
| **המרה ל-MP3** | כפתור "המר ל-MP3" — דורש `ffmpeg.exe` (בתיקיית התוכנה או ב-PATH). קובץ שכבר MP3 פשוט מועתק (ללא המרה מיותרת). |
| **העברה אמיתית (גזור+הדבק)** | "✂️ גזור" מסמן קבצים, "📋 הדבק כאן" מעביר אותם לתיקייה הנוכחית. |
| **הוצאה בטוחה** | כפתור "⏏ הוצאה בטוחה" מנתק את הכונן בבטחה דרך Windows. |
| **מטא-דאטה** | עמודות כותרת/אמן/אלבום נקראות מתגיות ID3/FLAC (מועיל לקבצים שהועתקו משירותי שיעורים חיצוניים). |
| **תצוגת סמלים** | אפשרות בהגדרות: רשימה או סמלים גדולים (עם תמונת אלבום אם מורשה). |
| **היסטוריית סשן** | כפתור "📜 היסטוריה" — מה הועתק/הועבר/הומר בסשן הנוכחי. |
| **ביטול העתקה** | כפתור ביטול בחלון ההתקדמות (עם אחוזים ופירוט הפעולה הנוכחית). |
| **שינוי שם חכם** | חלון שינוי השם משנה רק את בסיס השם — הסיומת נשמרת. |
| **בחירת טווח** | תיבות סימון + Ctrl לבחירה נפרדת + Shift לבחירת טווח. |
| **כפילות חכמה** | לפני העתקה — דיאלוג: "העתק והחלף / שמור את שניהם / דלג / ביטול". |
| **גלגל שיניים עם סיסמה** | ההגדרות מוגנות בסיסמה (מאוחסנת כ-scrypt hash). בהפעלה ראשונה — אין סיסמה ומוצג מסך הגדרה. |
| **פונקציות סייר רגילות** | שינוי שם, מחיקה לאשפה של ווינדוס, מיון לפי עמודות, חיפוש, בחירת הכל, העתקה עם הודעת כפילות. |

## על זיהוי התקן (השאלה שלכם על המספר הסריאלי)

התוכנה **מציגה** למקליט את המספר הסריאלי של ההתקן המחובר (דרך PowerShell),
ואפשר לקשור אותו לחשבון — אבל חשוב לדעת את האמת:

> בקוראי כרטיסים (SD/מיקרו-SD) זולים, המספר הסריאלי שחוזר הוא **של הקורא**, לא של הכרטיס —
> כלומר כל הכרטיסים שנועצים באותו קורא יראו אותו מספר, וזה לא מאפשר להבחין בין הכרטיס של
> בחור לשלב חבירו. גם בטלפון, הזיהוי תלוי ביצרן ובמצב ה-MTP.

המסקנה המעשית (וגם ההמלצה שלכם): **שם משתמש + סיסמה + היסטוריית העלאות** היא השיטה
האמינה. הזיהוי הסריאלי מוצג כמידע וככלי עזר — לא כמנגנון האבטחה הראשי.

## פרסום לגיטהאב (מאגר פרטי)

המאגר המקומי כבר מאותחל עם הקומיט הראשון. כדי לפרסם למאגר **פרטי** בגיטהאב:

1. צרו בגיטהאב מאגר חדש (New repository) ובחרו **Private**.
2. החזירו כאן את כתובת ה-URL (או הדביקו אותה במקום `URL`) והריצו:

```bash
cd kosher-file-station
git remote add origin URL
git push -u origin main
```

> `config.json`, `users.json` והיסטוריה **לא** נכללים בקומיט (ראו `.gitignore`) —
> ייצא לאוויר עולם רק הקוד עם `config.example.json`.
> אחרי הפרסום — דלגו על התיקיות `dist/`, `shell/**/obj` ו-`shell/**/bin`
> (נוצרות ע"י `build-dist.bat`).

## קבצים ותיקיות

| קובץ | תפקיד |
|---|---|
| `server.js` | השרת המקומי (API + ממשק) |
| `lib/filter.js` | מנוע הסינון (נבדק ביחידות) |
| `lib/audio.js` | קריאת אורך הקלטות + זיהוי תוכן + המרה |
| `lib/drives.js` | זיהוי כוננים, סוג, שטח פנוי, סריאלי |
| `lib/copy.js` | העתקה עם התקדמות, אשפה, בדיקת מקום |
| `lib/users.js`, `lib/store.js` | מקליטים, היסטוריה, יומן |
| `config.json` | הגדרות (מוגן בסיסמה דרך הממשק) |
| `users.json` / `history.json` / `audit.log` | נתוני העמדה |
| `ffmpeg/` (אופציונלי) | שימו כאן `ffmpeg.exe` להמרה ל-MP3 |
| `shell/` | מעטפת חלון .NET (WebView2) — מרכיבה את `shiurim-station.exe` |
| `dist/` | תיקיית הפצה: exe + node.exe מאורז + קבצי התוכנה (נוצרת ע"י `build-dist.bat`) |

**שימו לב:** `config.json` הנוכחי הוא **מצב דמו** — כולל את כונן `C:` ברשימת הכוננים
המורשים ואת ספריית `library-demo`. להפעלה אמיתית יש לעבור על ההגדרות (גלגל השיניים),
להגדיר סיסמה, כוננים נכונים וספריית שיעורים.

> בסביבת הדמו: משתמש המקליט `בחור-מקליט` / `rec1234` מורשה לרב "הרב כהן".
> לאחר בדיקה — מחקו את `users.json` ו-`history.json` והגדירו סיסמה משלכם.

## אבטחה

- השרת מקשיב **רק** על `127.0.0.1` — אין גישה מהרשת.
- סיסמאות מאוחסנות כ-scrypt hash, לעולם לא כטקסט.
- הפעלות (sessions) בזיכרון בלבד, עם תוקף.
- שום נתון לא יוצא מהמחשב.
